# Building an Android client powered by a Grails backend

This repository contains the worked sample app for the [Building an Android client powered by a Grails backend](https://grails.apache.org/guides/building-an-android-client-powered-by-a-grails-backend/4/guide/index.html) guide on the Apache Grails site.

## Run the example

`./gradlew bootRun`

## Maintained at apache/grails-static-website

The guide narrative is maintained at https://github.com/apache/grails-static-website. Changes to the guide content go there; this repo holds the worked sample app only.
